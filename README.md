# Нейромодель распознавания сканов договоров с веб-интерфейсом

Данный проект представляет собой полноценное веб-приложение на базе **Streamlit**, предназначенное для автоматического распознавания текста со сканов договоров (изображений формата PNG, JPEG или PDF) и извлечения из них ключевых сущностей с использованием современных ИИ-технологий.

## Принцип работы системы

Процесс обработки каждого загруженного документа состоит из трех основных этапов:

### 1. Предварительная обработка и конвертация
* **Загрузка:** Пользователь загружает файл через веб-интерфейс. Система поддерживает изображения (`.jpg`, `.jpeg`, `.png`) и многостраничные документы (`.pdf`).
* **Конвертация PDF:** Если загружен PDF-файл, библиотека `pdf2image` преобразует его страницы в растровые изображения (объекты `PIL.Image`).
* **Оптимизация:** При необходимости изображения могут быть бинаризированы или приведены к оптимальному DPI для улучшения качества последующего распознавания.

### 2. Оптическое распознавание символов (OCR)
Для извлечения сырого текста из изображений используется мультиязычная OCR-модель **EasyOCR** (или Tesseract/PaddleOCR в зависимости от конфигурации):
* Модель локализует текстовые блоки на скане (текстовые детекторы на базе архитектуры CRAFT).
* Сверточная нейросеть (CNN) совместно с рекуррентной сетью (LSTM) распознает символы с учетом контекста русского и английского языков.
* На выходе формируется структурированный массив строк, полностью повторяющий текстовое содержание скана.

### 3. Извлечение сущностей (Интеллектуальный анализ)
Чтобы превратить сплошной текст в структурированные данные, применяется архитектура **Transformers** от Hugging Face:
* **Базовый вариант:** Предобученная модель NER (Named Entity Recognition), например, на базе `DeepPavlov/rubert-base-cased`, находит в тексте ФИО, даты, названия организаций и денежные суммы.
* **Продвинутый вариант (LLM/Zero-Shot):** Использование zero-shot классификаторов или локальных моделей класса Mistral/Llama (через API или vLLM) для извлечения специфичных для договоров полей: номера договора, предмета соглашения, реквизитов сторон и срока действия.

---

## Архитектура приложения

* **Фронтенд:** Streamlit — обеспечивает легковесный и интерактивный интерфейс прямо в браузере.
* **Бэкенд-логика:** Python-скрипты, связывающие OCR-движок и NLP-модели.
* **Хранилище:** Временное кэширование результатов в оперативной памяти для быстрой выгрузки в форматы JSON/TXT.
